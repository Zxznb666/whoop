## 6.1 视觉基调 + OVERVIEW 页

```
【空间】VIGOR（恢复面板）。【这一步只改外观，不要重新计算任何数字，只读取已保存的结果】

一、整体样式（所有页面通用）
- 背景纯黑 #000000；卡片 #121619，圆角 12，内边距 16；分隔线和圆环轨道 #1F262B。
- 主文字 #FFFFFF；次要文字 #8A979F。
- 数字用 Barlow Condensed 粗体；英文标签用 Inter，全大写、11 号、字间距 0.12em、次要文字色；中文说明用苹方，13 号。
- 颜色语义：RECOVERY 高(≥67) #16EC06、中(34–66) #FFDE00、低(≤33) #FF0026；STRAIN #0093E7；SLEEP #7BA1BB；强调/睡眠需求 #00F19F；HRV 数值 #67AEE6；数据质量低 #5A646B。
- 底部四个标签：OVERVIEW / RECOVERY / STRAIN / SLEEP。顶部是日期切换“‹ 11月12日 周三 ›”，切换的是醒来日。
- 圆环：轨道 #1F262B，进度线宽 10、圆头，从 12 点方向顺时针；环中心是大号数字，下方是全大写标签。
- 每个分数旁边：质量小圆点（高 #16EC06 / 中 #FFDE00 / 低 #5A646B），点开显示原因；以及“数据截至 HH:MM”。
- 缺失值显示“—”和一句原因，不显示 0。

二、OVERVIEW 页（从上到下）
1. 日期切换 + 质量圆点 + 数据截至。
2. 三个圆环一行：左 SLEEP（SLEEP PERFORMANCE %，#7BA1BB），中 RECOVERY（%，按分区着色，比两侧大一圈），右 STRAIN（0–21，#0093E7，进度 = 值 ÷ 21，旁边小字“估算”）。
3. 2×2 数据卡：HRV（ms，数值用 #67AEE6）、RHR（bpm）、RESP RATE（rpm）、HOURS OF SLEEP（h:mm）。每张卡下方：和基线相比的 ▲/▼（与基线之差小于 0.5σ 时显示“—”）+ 基线值。对恢复有利的方向用 #00F19F，不利用 #FF0026；HRV 升高有利，RHR 和呼吸率下降有利，睡眠时长增加有利。
4. 底部一句中文：“恢复 xx%，今天适合 a–b 的负荷”（目标负荷取“恢复”表里的值）。
5. “未佩戴”的日子：中间圆环画空心灰环，写“昨晚未佩戴”，不显示数字；“没有 HRV”的日子同样不显示数字，写原因。
6. RECOVERY 环下方一行小字：“HRV 为睡眠时段内每小时平均”。
```

## 6.2 RECOVERY 页

```
【空间】VIGOR（恢复面板）。【只做 RECOVERY 页，只改外观，只读已保存的结果，沿用已有的整体样式】
1. 大圆环（按分区着色）+ 分区名 HIGH / MEDIUM / LOW + 质量圆点和原因。
2. 贡献列表，每行：标签、当日值、基线、▲/▼：HRV、RHR、RESP RATE、WRIST TEMP（显示与基线的偏差 ±x.xx°C）、SPO2、SLEEP PERFORMANCE。某项扣分大于 0 时，在该行右侧用 #FF0026 写“−x.xx”。
3. 近 7 天柱状图：柱高 = RECOVERY，柱色按分区；没戴表或没有 HRV 的那天画灰色虚线框，下方写“未佩戴”或“无 HRV”。
4. 有“信号矛盾”“注意”“可能不适”时，在圆环下方用一行中文说明（例如“体温和呼吸率同时升高，可能不适，恢复最高按 33% 计”）。
```

## 6.3 STRAIN 页

```
【空间】VIGOR（恢复面板）。【只做 STRAIN 页，只改外观，只读已保存的结果，沿用已有的整体样式】
1. 当日 STRAIN：大号数字（1 位小数）+ 0–21 的蓝色弧（#0093E7，轨道 #1F262B）；弧上用 #00F19F 标出今日目标负荷区间；数字旁小字“估算”。
2. 全天心率：横轴 = 本周期（醒来 → 下次入睡或现在），纵轴 bpm；用“负荷”表里保存的每小时平均心率画折线（#0093E7，点之间直线相连）；训练所在的时段背景用 #0093E7 的 15% 透明度高亮；没有数据的小时断开不连线。图下小字“每小时平均心率”。
3. 构成条：一条横向堆叠条，左段“训练 TRIMP”（#0093E7）、右段“日常活动 TRIMP”（#7BA1BB），下面标两个数和周期 TRIMP 合计。
4. 训练列表：类型、开始时间、时长、STRAIN、平均/最高心率。没有训练写“本周期没有训练记录”。
5. 底部小字：负荷比 ACWR（为空时写“历史不足 7 天”）。
```

## 6.4 SLEEP 页

```
【空间】VIGOR（恢复面板）。【只做 SLEEP 页，只改外观，只读已保存的结果，沿用已有的整体样式】
1. SLEEP PERFORMANCE 大号百分数（#7BA1BB）+ 质量圆点。
2. 两条横条：实际睡眠（#7BA1BB）和睡眠需求（#00F19F），长度按小时成比例，右侧写 h:mm；需求下方小字列出：基础 7:30 / 负荷追加 / 还债 / 小睡抵扣。
3. 睡眠分期：四行横向色块条，从上到下 AWAKE #E5E5E5、REM #00F19F、LIGHT #7BA1BB（即“核心”）、DEEP #5B3FD9；每行条长 = 该分期分钟 ÷ 四项中最长的那项，右侧写时长和占睡着时长的百分比。小字注明“只有整晚总量，没有时间线”。
4. 指标网格（2 列）：入睡、起床、效率、睡眠负债、修复性睡眠、睡眠分。
```
