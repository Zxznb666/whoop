## 步骤 7 · OVERVIEW 页

```
{共用前言}
【只做 OVERVIEW 页，用已保存的结果】
1. 顶部：日期切换 + 质量小圆点（高 #16EC06 / 中 #FFDE00 / 低 #5A646B）+ “数据截至 HH:MM”。
2. 三个圆环一行：左 SLEEP（Sleep Performance %，#7BA1BB），中 RECOVERY（%，按分区着色，比两侧大一圈），右 STRAIN（0–21，#0093E7，进度 = 值 ÷ 21）。圆环：轨道 #1F262B，进度线宽 10、圆头，从 12 点方向顺时针；环中心是大号数字，下方是全大写标签。
3. 2×2 数据卡：HRV（ms）、RHR（bpm）、RESP RATE（rpm）、HOURS OF SLEEP（h:mm）。每张卡下方：与基线相比 ▲/▼（差不到 0.5σ 显示“—”）+ 基线值；对恢复有利的方向用 #00F19F，不利用 #FF0026（RHR、呼吸率下降算有利）。
4. 底部一句中文：“恢复 xx%，今天适合 a–b 的负荷”（绿 14–18、黄 10–14、红 0–10）。
5. 昨晚未佩戴：中间圆环画空心灰环，写“昨晚未佩戴”，不显示数字。
```
B 档在 RECOVERY 环下加小字“HRV 含日间读数”，STRAIN 旁加“估算”；C 档所有分数旁加“低精度”。

## 步骤 8 · RECOVERY 页

```
{共用前言}
【只做 RECOVERY 页】
1. 大圆环 + 分区名 HIGH / MEDIUM / LOW + 质量圆点和原因。
2. 贡献列表，每行：标签、当日值、基线、▲▼：HRV、RHR、RESP RATE、WRIST TEMP（显示与基线的偏差 ±x.xx°C）、SPO2（仅 A 档）、SLEEP PERFORMANCE。某项扣分生效时，该行右侧写“−x 分”。
3. 近 7 天柱状图：柱高 = RECOVERY，柱色按分区；没戴表的那天画灰色虚线框，标“未佩戴”。
4. 有“信号矛盾”或“注意/可能不适”时，在圆环下方用一行中文说明。
```

## 步骤 9 · STRAIN 页

```
{共用前言}
【只做 STRAIN 页】
1. 当日 STRAIN：大号数字 + 0–21 的蓝色弧（#0093E7）；弧上用 #00F19F 标出今天的目标区间。
2. 全天心率曲线（A 档）：横轴 = 本周期（醒来 → 现在或下次入睡），线 #0093E7；训练时段背景浅蓝高亮；未佩戴时段断线，底部画灰条。
   画不出曲线时：改成每小时平均心率的柱状图，训练所在小时蓝色，其余灰色。
   B/C 档不画曲线，改为“训练 TRIMP + 日常活动 TRIMP”两段横条。
3. Z1–Z5 五行横条（A 档），标分钟数。
4. 训练列表：类型、开始时间、时长、STRAIN、平均/最高心率。
```

## 步骤 10 · SLEEP 页

```
{共用前言}
【只做 SLEEP 页】
1. SLEEP PERFORMANCE 大号百分数（#7BA1BB）。
2. 两条横条：实际睡眠（#7BA1BB）和睡眠需求（#00F19F）；需求下方小字列出：基础 7.5h / 负荷追加 / 还债 / 小睡抵扣。
3. 睡眠分期图（A/B 档）：四行，从上到下 AWAKE #E5E5E5、REM #00F19F、LIGHT #7BA1BB、DEEP #5B3FD9；横轴 = 入睡到醒来，每个分段按实际起止时间画在所在行。画不出时改为四行按时长比例的色块条。C 档不画。
4. 分期时长表：色块、名称、时长、占睡着时长的百分比。
5. 指标网格：效率、规律性 SRI、睡眠负债、入睡/起床时间、觉醒次数。
```

## 修正提示词

**数字不对**（把 `{}` 换成对比结果）：

```
{验收日} 的 {字段} 你给的是 {Muse 值}，按规则应为 {golden 值}。
请按 {步骤 n} 的第 {k} 步重新逐步计算这一天，把每一步的中间值列出来（包括用到的原始样本条数、排序后的取值位置），找出哪一步与规则不一致，只修正那一步的做法，然后重算并保存受影响的日子。不要改动其他步骤，也不要改动其他日子的已保存结果（除非它们依赖这个值，例如基线和睡眠负债）。
```

**每次打开数字不一样**：

```
同一天的 {字段} 三次打开分别是 {a}、{b}、{c}。请不要在打开时重新计算历史日子：只读取已保存的结果；只有出现新的醒来日时才计算那一天并追加保存。改完后告诉我保存的结果放在哪里、什么时候会被写入。
```

**视觉不对**：

```
【只改外观，不改数字】{页面} 的 {组件} 现在是 {现状}，应该是 {DESIGN.md 对应描述，带色值和几何}。只改这一处。
```
