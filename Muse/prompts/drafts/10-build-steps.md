## 步骤 1 · 数据层：只建原始特征表（不出分数）

### A 档版本

```
{共用前言}

【这一步只做一件事】在 VIGOR 空间里建一张“夜间特征”表，最近 30 个醒来日每天一行。先不要算任何分数。

【一晚的睡眠窗口】
1. 取 Apple Health 睡眠分析的分段（清醒、核心、深度、REM、未指定、在床）。两个分段时间重叠时，保留来源为 Apple Watch 的那个。
2. 按开始时间排序，相邻分段间隔 ≤ 45 分钟的合并成一段睡眠；间隔 45–120 分钟、且两端都在 19:00 到次日 11:00 之间的也合并。
3. 入睡 = 第一个非清醒分段（核心/深度/REM/未指定）的开始；醒来 = 最后一个非清醒分段的结束。
4. 睡着时长 = 窗口内核心 + 深度 + REM + 未指定的总时长。睡着时长 ≥ 3 小时的才是主睡眠；同一晚有多个时取最长的。醒来时刻所在的日期叫“醒来日”。
5. 某个醒来日没有主睡眠：这一行写“昨晚未佩戴”，其余列为“—”。

【每列的算法（窗口两端都包含）】
- HRV(ms)：开始时间落在睡眠窗口内的全部 HRV(SDNN) 记录，取中位数，保留 1 位小数。另列“HRV 条数”。
- 夜间静息心率(bpm)：窗口内的心率样本，去掉落在持续 ≥ 5 分钟的“清醒”分段里的样本；剩余 ≥ 10 个时，把它们从小到大排序，取第 10 百分位：位置 = 0.1 × (个数 − 1)，整数部分 i、小数部分 f，结果 = 第 i 个 + (第 i+1 个 − 第 i 个) × f（从第 0 个数起）。不足 10 个时用醒来日 Apple 给的静息心率，并在“静息心率来源”列写“Apple 每日值”。保留 1 位小数。
- 呼吸率(次/分)：开始时间在窗口内的呼吸频率记录的中位数（至少 3 条），1 位小数。
- 手腕温度(°C)：结束时间在醒来日的那一条睡眠手腕温度，2 位小数。
- 血氧(%)：开始时间在窗口内的血氧记录，{若 Apple Health 给的是 0–1 的小数则 × 100}，取中位数（至少 3 条），1 位小数。
- 睡着时长(h:mm)、入睡时刻、醒来时刻(HH:MM)。
- 深睡、REM、核心、清醒各自的分钟数（窗口内分段直接相加）。

表格下方写“数据截至 HH:MM”。做完后，把 {验收日} 这一行的每一列告诉我。
```

## 步骤 2 · 个人基线

```
{共用前言}

【这一步只做一件事】在“夜间特征”表右侧加“基线”几列。不要改动已有列的数值。

【基线的算法：第 N 天的基线只用第 N 天之前的数据，不含当天】
对 HRV、夜间静息心率、呼吸率、手腕温度、血氧、睡着时长、修复性睡眠（深睡 + REM，小时）各自：
1. 取第 N 天之前、这一项有值、并且不是“未佩戴”的日子，按日期排好，只留最近 30 个，个数记为 n。
2. HRV 先取自然对数 ln 再统计；其余直接用原值。
3. 个人中位数 m；MAD = 每个值与 m 之差的绝对值的中位数；个人 σ = 1.4826 × MAD。
4. n ≥ 30：μ = m，σ = 个人 σ。n < 30：μ = (7 × 先验μ + n × m) ÷ (7 + n)，σ = (7 × 先验σ + n × 个人σ) ÷ (7 + n)（n = 0 时 m 和个人 σ 都按 0 算）。
   先验：ln HRV 的 μ = ln({按年龄：<30 岁 60，30–39 岁 52，40–49 岁 45，50–59 岁 40，≥60 岁 35})、σ = 0.30；静息心率 μ = {男 55 / 女 58}、σ = 5；呼吸率 14.5、1.2；血氧 96.5、1.0；睡着时长 7.0、0.6；修复性睡眠 2.6、0.5；手腕温度没有先验 μ（n = 0 时 μ 为空）、σ = 0.25。
5. σ 不得小于下限：ln HRV 0.06；静息心率 1.5；呼吸率 0.3；手腕温度 0.15；血氧 0.5；睡着时长 0.1；修复性睡眠 0.1。
6. n < 4 时这一项标“基线建立中”。

显示：HRV 基线显示为 e^μ（毫秒），其余显示 μ。另列每项的 n。做完后告诉我 {验收日} 每一项的 μ、σ、n。
```

**验收**：对 `golden/.../A.json` 里该日的 `recovery.baselines`。

## 步骤 3 · 恢复分数 Recovery

```
{共用前言}

【这一步只做一件事】用已保存的特征和基线，给每个醒来日算 RECOVERY（0–100%）。

1. z 值（每个都截到 −3 到 3 之间）：
   z_hrv = (ln(当晚 HRV) − HRV 基线 μ) ÷ σ
   z_rhr = −(静息心率 − μ) ÷ σ
   z_resp = (呼吸率 − μ) ÷ σ（只用于扣分）
   z_sleep = (睡眠分 − 80) ÷ 12（睡眠分来自步骤 4；步骤 4 还没做时先不算这一项）
2. 若 z_hrv > 2 且 z_rhr < −1：z_hrv 改为 1，并标“信号矛盾”。
3. 权重 HRV 0.55、静息心率 0.25、睡眠 0.20；缺哪项就把剩下的按比例放大到合计 1。没有 HRV → 不出分，写“睡眠期间没有 HRV 记录”。
4. 扣分（缺数据的项为 0）：
   呼吸 = min(0.6, 0.3 × max(0, z_resp − 1.0))
   体温 = min(1.2, 0.8 × max(0, Δt − 0.3) ÷ 0.5)，Δt = 手腕温度 − 温度基线 μ（μ 为空时 Δt = 0）
   血氧 = min(0.4, 0.1 × max(0, 95 − 血氧中位数))
5. raw = Σ(权重 × z) − Σ扣分
6. RECOVERY = 100 ÷ (1 + e^(−(1.4 × raw + 0.35)))，保留 1 位小数。
7. 分区：≥ 67 绿，34–66 黄，≤ 33 红（用未取整的值判断）。
8. 生病预警：T = Δt ≥ 0.5；R = z_resp ≥ 1.5；H = z_hrv ≤ −1.5；C = 静息心率 ≥ μ + 2σ。T 成立且 R/H/C 至少一个成立，或 R、H、C 同时成立 → “注意”。连续两晚“注意”（两次醒来相隔 ≤ 36 小时）→ “可能不适”：RECOVERY 最高 33，这两晚以后不再进入基线。

列出 {验收日} 的 z_hrv、z_rhr、z_resp、Δt、各扣分、raw、RECOVERY、分区。
```

B 档：去掉血氧扣分；C 档：去掉第 4、8 步，只用 z_hrv、z_rhr、z_sleep。

**验收**：`A-days.csv` 的 `z_hrv`、`z_rhr`、`recovery`、`zone`；恢复 ±3 个百分点且分区一致。

## 步骤 4 · 睡眠

```
{共用前言}

【这一步只做一件事】给每个醒来日算睡眠指标，按日期从早到晚逐日计算（负债要递推）。

1. 效率 = 睡着时长 ÷ (醒来 − 上床)；没有“在床”记录时用 睡着时长 ÷ (醒来 − 入睡)。
2. 修复性睡眠 = 深睡 + REM（小时）；z_修复 = (修复性睡眠 − 基线 μ) ÷ σ。
3. 睡眠需求（小时）：
   负荷追加 = min(52, 4 × max(0, 前一天 STRAIN − 8)) ÷ 60
   小睡抵扣 = 上次醒来后、这次入睡前的小睡睡着时长 × 0.8
   N0 = 7.5 + 负荷追加 − 小睡抵扣
   还债 = min(2, 0.3 × 前一天的睡眠负债)
   需求 = N0 + 还债
4. 睡眠负债 = clip(0.8 × 前一天负债 + (N0 − 睡着时长), 0, 10)；第一天的“前一天负债”= 0。
5. SLEEP PERFORMANCE = min(1, (睡着时长 + 小睡抵扣) ÷ 需求) × 100%。
6. 睡眠分 = 100 × (0.55 × 时长达成 + 0.15 × 效率分 + 0.15 × 一致性分 + 0.15 × 修复分) ÷ 在场权重之和
   时长达成 = 第 5 步的比值；效率分 = clip((效率 − 0.75) ÷ 0.20, 0, 1)；修复分 = clip(0.5 + 0.25 × z_修复, 0, 1)
   一致性分 = SRI ÷ 100（SRI 的算法见附录；做不到时去掉这一项，权重按比例分给其余三项，并告诉我）
保存每天的需求、负债、Performance、睡眠分。列出 {验收日} 的各项。
```

附录 SRI（A/B 档）：照抄 `ALGORITHM.md` §4.2 第 5 步。

**验收**：`needH`、`debtH`、`performance`、`sleepScore`、`sri`。

## 步骤 5 · 负荷 Strain

### A 档版本

```
{共用前言}

【这一步只做一件事】给每个周期算 STRAIN（0–21）。周期 = 某次主睡眠醒来 → 下一次主睡眠入睡（还没睡就到现在）。

参数：静息心率 RHR = 夜间静息心率基线 μ；最大心率 HRmax = max(208 − 0.7 × 年龄, 以往训练中按 30 秒平均的最高心率)。
1. 把周期内的心率样本按分钟归档，同一分钟取平均。
2. 没有样本的分钟：前后最近的有样本分钟相距 ≤ 15 分钟 → 线性插值；> 60 分钟 → 记为未佩戴，不计；其余按 RHR。
3. 每分钟 x = clip((心率 − RHR) ÷ (HRmax − RHR), 0, 1)；x < 0.25 记 0；否则 TRIMP = x × 0.64 × e^(1.92x)（男性；女性 x × 0.86 × e^(1.67x)）。
4. 周期 TRIMP = 每分钟之和；STRAIN = min(21, 5.3 × ln(1 + TRIMP ÷ 10))，1 位小数。
5. 每次训练同样单独算一个 STRAIN，列出类型、时间、时长、平均和最高心率。
6. 统计未佩戴分钟数，以及 x 在 0.5–0.6、0.6–0.7、0.7–0.8、0.8–0.9、≥ 0.9 的分钟数（Z1–Z5）。
7. 目标区间：今天恢复绿 14–18、黄 10–14、红 0–10。
列出 {验收日} 的 TRIMP、STRAIN、未佩戴分钟、各区间分钟、每次训练的 STRAIN。
```

### B 档版本

```
（参数同上；HRmax 用以往训练记录里的最高心率）
1. 周期内每次训练：TRIMP = 训练分钟 × 每分钟 TRIMP（x 用训练平均心率算）。
2. 非训练活动能量 = 醒来日活动能量总和 − 当天各训练的活动能量。
3. 非训练 TRIMP = 0.075 × max(0, 非训练活动能量 − 300)。
4. STRAIN = min(21, 5.3 × ln(1 + 总 TRIMP ÷ 10))，旁边标“估算”。
```

### C 档版本

```
TRIMP = 训练分钟 × 1.01 + 0.075 × max(0, 活动能量 − 8 × 训练分钟 − 300)；STRAIN 同上公式，标“低精度”。
（1.01 = 男性 x = 0.55 时的每分钟 TRIMP；女性用 0.86 × 0.55 × e^(1.67 × 0.55) = 1.18）
```

**验收**：`strain` ±0.5、`trimp`。
