# Muse 空间视觉规格（WHOOP 风格）

> 版本：muse-design 1（2026-11-13）
> 样机：`Muse/mock/index.html`（单文件，内嵌 golden 数据，手机宽度优先；用浏览器打开即可）。生成：`cd Muse/reference && node scripts/build-mock.js`。
> 用途：①给你确认视觉；②截图后作为参考图附给 Muse（如果探测 P8 显示它能看图）。
> 不使用 WHOOP 的商标、Logo 和图形资产；只借鉴配色、层级和图表类型。

---

## 1. 颜色

已对照 WHOOP 官方《Brand & Design Guidelines》（developer.whoop.com 上的 PDF）核对，施工文档给出的色值全部一致。

| 用途 | 色值 | 官方说明 |
|---|---|---|
| 背景 | `#000000` | 品牌黑 |
| 卡片 | `#121619`（在官方背景渐变 `#283339 → #101518` 的暗端取一个纯色，比纯黑亮一档） | 背景渐变 |
| 卡片描边 / 分隔线 / 圆环轨道 | `#1F262B` | — |
| 主文字 | `#FFFFFF` | 品牌白 |
| 次要文字 | `#8A979F`（白 55% 叠在卡片上的近似值） | — |
| Recovery 高（67–100%） | `#16EC06` | High Recovery |
| Recovery 中（34–66%） | `#FFDE00` | Medium Recovery |
| Recovery 低（0–33%） | `#FF0026` | Low Recovery |

## 2. 字体

WHOOP 用 Proxima Nova（正文）和 DIN Pro（数字），都是商业字体。替代：

| 角色 | 首选 | 依据 | 回退 |
|---|---|---|---|
| 大号数字、圆环中心值 | **Barlow Condensed** 700 | 和 DIN 一样源自道路标识字体的窄体几何无衬线，数字等宽、笔画粗细接近 | `DIN Alternate`（iOS 自带）→ `Arial Narrow` |
| 全大写标签、正文 | **Inter** 500/600 | 中性的几何人文无衬线，字面宽度和 x 高度接近 Proxima Nova；Google Fonts 和多数平台都有 | `-apple-system` / `SF Pro` |
| 中文说明 | **PingFang SC** | iOS 系统中文字体 | `Noto Sans SC` |

字号：圆环中心值 44px / 粗；卡片数值 28px；全大写标签 11px、字间距 0.12em、次要文字色；说明文字 13px。

## 3. 通用组件

- **圆环**：轨道 `#1F262B`，进度描边 10px、圆头，12 点方向起顺时针。中心：大号数值 + 下方全大写标签。数据质量低时进度色改为 `#5A646B`，旁边注明原因。
- **数据卡**：深灰卡片，圆角 12px，内边距 16px。上：全大写标签；中：数值 + 单位（单位小一号、次要色）；下：相对基线的箭头 ▲▼（与基线差 < 0.5σ 显示“—”）和基线值。箭头颜色按“对恢复有利/不利”上色：有利 `#00F19F`、不利 `#FF0026`（例如静息心率下降是有利）。
- **质量与时间**：每个分数旁边一个小圆点（高 `#16EC06`、中 `#FFDE00`、低 `#5A646B`）+ “数据截至 HH:MM”。点开显示原因列表。
- **降档标注**：B 档在 HRV 卡和 Recovery 圆环下写“HRV 含日间读数”，Strain 旁写“估算”；C 档所有分数旁写“低精度”，睡眠页不画分期图。
- **未佩戴**：Recovery 圆环位置显示空心灰环和“昨晚未佩戴”，不显示数字；Strain 照常显示（白天有数据时）。
- **不编数**：任何缺失的值显示“—”并给一句原因，不显示 0。

## 4. 页面

页面顺序：概览、恢复、负荷、睡眠。底部四个标签：OVERVIEW / RECOVERY / STRAIN / SLEEP。顶部是日期切换（‹ 11月12日 周三 ›），切换的是“醒来日”。

### 4.1 概览 OVERVIEW

1. 日期切换 + 质量圆点 + 数据截至。
2. 三个圆环一行：**SLEEP**（Sleep Performance %，`#7BA1BB`）、**RECOVERY**（%，按分区着色）、**STRAIN**（0–21，`#0093E7`，进度 = 值 ÷ 21）。中间的 Recovery 环略大。
3. 四张关键数据卡（2 × 2）：**HRV**（ms）、**RHR**（bpm）、**RESP RATE**（rpm）、**HOURS OF SLEEP**（h:mm），各带相对基线的箭头。
4. 一句中文概括：按分区给出今天的建议负荷区间，例如“恢复 72%，今天适合 14–18 的负荷”。

### 4.2 恢复 RECOVERY

1. 大圆环 + 分区名（HIGH / MEDIUM / LOW 对应绿/黄/红）+ 质量与原因。
2. 贡献项列表（每行：标签、当日值、基线、偏离方向）：HRV、RHR、RESP RATE、WRIST TEMP（显示偏差 ±°C）、SPO2、SLEEP PERFORMANCE。扣分项生效时在该行右侧显示“−x 分”。
3. 近 7 天柱状图：柱高 = Recovery，柱色按分区；没戴表的那天画灰色虚线占位并标“未佩戴”。
4. 可选：贡献拆解（Shapley），从 59% 出发逐项加减到当天分数。

### 4.3 负荷 STRAIN

1. 当日 Strain（大号数字 + 0–21 的蓝色弧）+ 由恢复给出的目标区间（弧上用青绿色标出区间）。
2. 全天心率曲线：横轴为本周期（醒来 → 现在/下次入睡），线 `#0093E7`；训练时段背景高亮；未佩戴时段断线并在底部标灰条。
3. 心率区间时长条：Z1–Z5 五行横条，标分钟数。
4. 训练列表：类型、时间、时长、Strain、平均/最高心率。

### 4.4 睡眠 SLEEP

1. **SLEEP PERFORMANCE** 大百分数（`#7BA1BB`）。
2. 实际睡眠 vs 睡眠需求：两条横条（实际 `#7BA1BB`、需求 `#00F19F`），需求下方小字列构成（基础 / 负荷追加 / 还债 / 小睡抵扣）。
3. 睡眠分期图：四行（AWAKE、REM、LIGHT、DEEP），横轴为入睡到醒来，每段画在所在行。
4. 各分期时长和占比（四行：色块、名称、时长、占睡眠时长百分比）。
5. 指标网格：效率、规律性（SRI）、睡眠负债、入睡与起床时间、觉醒次数。

## 5. 给 Muse 的描述要点（阶段 4 提示词会用）

Muse 只能听文字描述，所以每次描述视觉时都带上：①具体色值；②组件的几何（圆环环宽、起点、方向）；③层级顺序；④缺数据时的样子。如果探测 P7 显示某种图画不出来，替代方案：

| 画不出 | 替代 |
|---|---|
| 圆环 | 大号数字 + 下方一条横向进度条（同色） |
| 分期图 | 四行横向色块条，按时长比例 |
| 心率曲线 | 按小时的柱状图（每小时平均心率），训练小时用蓝色、其余灰色 |
| 指定颜色 | 用“绿/黄/红”文字标签代替颜色 |
